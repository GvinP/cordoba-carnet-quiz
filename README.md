# Билеты ПДД — Кордоба, категория B

Telegram Mini App для подготовки к теоретическому экзамену на водительские
права категории B в Кордобе, Аргентина. Каждый вопрос показан на испанском
(как в реальном билете) и на русском.

Собран на чистых HTML/CSS/JS, использует
[Telegram Web App JS SDK](https://core.telegram.org/bots/webapps) —
подхватывает тему Telegram и даёт лёгкий haptic-фидбек на ответах. Открытый
вне Telegram (в обычном браузере) тоже работает, просто без интеграции с
ботом.

## Страницы

- `index.html` — главная: поиск и три карточки-раздела
- `browse.html` (+ `browse.js`) — список всех 205 билетов с ответами и живым
  поиском по тексту/номеру
- `practice.html` (+ `app.js`) — режим практики, параметризован через URL:
  - `practice.html?mode=all` — все 205 вопросов вперемешку, без ограничений
  - `practice.html?mode=exam` — 30 случайных вопросов, как на настоящем
    экзамене; сдал/не сдал считается по правилу «не более 4 ошибок»
  - обе версии умеют "повторить только ошибки" и показывают разбор
    неправильных ответов в конце

## Данные вопросов

- `questions.js` — все 205 билетов из официального набора, все играбельны
- ~29 вопросов помечены `verify: true` — ответ определён по совпадающим
  паттернам внутри самого билетника (лимиты алкоголя по категориям
  водителей, периодичность техосмотра, дистанция сигнала поворота и
  т.п.), а не сверен с официальным источником — в квизе и в списке такие
  вопросы показывают предупреждение
- часть вопросов несёт `image` (в самом вопросе) или `options[].image`
  (когда сами варианты ответа — картинки, как в билетах 53 и 58);
  картинки лежат в `images/`

Чтобы дополнить или исправить вопросы — редактируй `questions.js`, формат
описан в комментарии в начале файла.

## Деплой на GitHub Pages

1. **Settings → Pages → Source** → **GitHub Actions**
2. Пуш в `main` (или вручную: **Actions → Deploy to GitHub Pages → Run workflow**)
3. Ссылка появится в **Settings → Pages**, обычно
   `https://<username>.github.io/cordoba-carnet-quiz/`

## Подключение к боту в Telegram

1. Создай бота через [@BotFather](https://t.me/BotFather): `/newbot`
2. Добавь токен бота в **Settings → Secrets and variables → Actions** как
   секрет `TELEGRAM_BOT_TOKEN`
3. Запусти workflow **Actions → Set Telegram bot menu button → Run workflow**
   — он привяжет ссылку на этот квиз как кнопку меню бота через Bot API
   (`setChatMenuButton`), без ручных команд в BotFather
4. Открой бота в Telegram — кнопка меню откроет квиз внутри приложения
